
# Календарики A4: проверка, подготовка и импозиция

  

Приложение (Gradio + Pillow) для проверки изображений под печать календариков и сборки макета **A4 (альбом)** с метками реза.

Карточка: **100×70 мм обрез** + **вылеты 5 мм** по каждой стороне ⇒ итог **110×80 мм** @ **300 dpi**.

  

---

  

## Что делает программа

  

**Проверка (валидация):**

- Цветовое пространство: **CMYK** (только проверка, **без** автоконвертации из RGB).

- Обрезной формат: **100×70 мм** (контролируем итоговую карточку **110×80 мм** с вылетами).

- Разрешение: **300 dpi** (контролируем по требуемым пикселям 110×80 мм @300 dpi).

- Допустимые преобразования, если исходник можно привести к требованиям:

- пропорциональное уменьшение;

- увеличение **не более 50%** (scale ≤ 1.5);

- при избытке размера — масштабирование до **110×80 мм** (с учётом вылетов);

- при иных пропорциях — «**cover + crop**»: минимально необходимое увеличение (≤1.5×) с кропом по центру.

- Файлы, которые нельзя приводить (например, RGB), помечаются «нельзя» без попытки конвертации.

  

**Импозиция (сборка макета A4):**

- Лист: **A4, альбомная ориентация**, **300 dpi**.

- Раскладывает только **одобренные** карточки 110×80 мм.

- Настройки: строки/колонки, поля, интервалы, длина меток реза, формат вывода (TIFF LZW/JPEG).

- Рисует **пунктир на линии обреза** и **уголковые метки** по краям.

- CMYK режим сохранения:

-  **DeviceCMYK (без профиля)** или

-  **Embed ICC профиль** (загрузка файла профиля; поле появляется только при выборе этого режима).

- Предпросмотр первой страницы и упаковка всех страниц в ZIP — **по кнопке**.

- Контроль размера файла: рекомендуемые параметры и LZW/JPEG помогают держать итоговый файл ≤ 100 МБ.

  

**Отчёты:**

- Лог-отчёт формируется **по кнопке**: **CSV** и **XLSX**.

- Содержит: исходный файл, «соответствует/нет», причину отказа, выполненные преобразования, DPI/размеры, масштаб.

  

---

  

## Почему «горизонтальная карточка + альбомный A4» — оптимально

  

Сравним вместимость (без полей/интервалов, для наглядности):

  

-  **A4 портрет**: 210×297 мм

Карточка 110×80 мм ⇒ cols = floor(210/110) = **1**, rows = floor(297/80) = **3** ⇒ всего **3** карточки.

-  **A4 альбом**: 297×210 мм

Карточка 110×80 мм ⇒ cols = floor(297/110) = **2**, rows = floor(210/80) = **2** ⇒ всего **4** карточки.

  

С учётом полей и интервалов альбомная ориентация остаётся выгоднее практически во всех разумных настройках — поэтому в программе она зафиксирована. Это максимизирует выход с листа и упрощает интерфейс.

## Как пользоваться (UI-обзор)

  

### 1) Загрузка данных

В одном поле **можно одновременно**:

- загрузить **один или несколько файлов** изображений (поддерживаются: `.jpg, .jpeg, .tif, .tiff, .png, .bmp, .webp, .psd, .eps`);

- загрузить **ZIP-архив** с изображениями.

  

Программа сама разархивирует ZIP во временную папку и возьмёт подходящие файлы.

  

> ⚠️ EPS открываются через Ghostscript; PSD поддерживается в пределах Pillow.

  

### 2) Проверка и подготовка

- Нажмите **«🔍 Проверить и подготовить»**.

В таблице появятся результаты, а в колонке «Статус» — **OK** или **Нельзя**.

- Клик по строке — «Детали»: режим, DPI, исходные/целевые размеры, масштаб, какие преобразования выполнены и почему.

- Только **OK**-карточки (110×80 @300 dpi, CMYK) попадают в список для макета.

  

### 3) Сборка макета A4

- В блоке «Параметры A4 макета» задайте: **строки, колонки, поля, интервалы, длину меток реза**, формат вывода.

При некорректных значениях (отрицательное, ноль, слишком большое) — подставится дефолт и покажется сообщение.

- CMYK режим:

-  **DeviceCMYK** — сохраняем без профиля;

-  **Embed ICC профиль** — выберите файл **.icc/.icm** (поле появится только при выборе этого режима).

После сборки статус сообщит: профиль **встроен во все страницы** (или укажет номера страниц без профиля).

- Нажмите **«📄 Собрать A4 макет»** — увидите статус и предпросмотр первой страницы.

- Нажмите **«📦 Скачать ZIP макетов»**, чтобы скачать все страницы одним архивом.

  

### 4) Лог-отчёт

- Нажмите **«📑 Сформировать лог-отчёт»** — появятся кнопки для скачивания **CSV** и **XLSX**.

  

### 5) Генерация тестов (необязательно)

- На вкладке «Генератор тестовых изображений» — создаёт набор CMYK-тестов (цветные фигуры) для проверки пайплайна.

- Кнопка **«📥 Использовать тесты для проверки»** — быстро прогоняет валидатор по созданным примерам.

- Можно **скачать ZIP тестов** по кнопке.

  

> Приложение **не** сохраняет ничего автоматически — всё скачивается **по кнопке**.

## Запуск и подача данных

  

```bash

git  clone  https://git.miem.hse.ru/kg25-26/poalivanova.git

cd  poalivanova

docker  compose  up  --build

```

Открой в браузере: http://localhost:7860

  

Загрузите файлы/ZIP-архив для проверки изображений и нажмите «📤 Проверить загруженные» или сгенерируйте тесты
