# Проверка изображений для типографии  
CMYK · DPI · вылеты · безопасная зона текста (Tesseract OCR) · Gradio UI

## 1. Описание программы
Веб-приложение для проверки изображений на соответствие требованиям типографии и формирования отчёта.

Проверяется:
- Размер файла: ≤ 100 МБ  
- Цветовое пространство: **CMYK** (только валидация, без автоконвертации)  
- Обрезной формат: **100 × 70 мм**  
- Вылеты: **5 мм** с каждой стороны → холст **110 × 80 мм**  
- Разрешение: **≥ 300 dpi**  
- Текст: не ближе **5 мм к линии обреза**

Возможности:
- выбор отдельных файлов и пакетная проверка;
- быстрый пайплайн: сначала «физика» (размер/цвет/DPI/геометрия), затем OCR — это экономит время;
- таблица результатов + детальная сводка по выбранному файлу;
- экспорт в **Excel/CSV**;
- генератор тестовых изображений (создано дополнительно для провеки работоспособности программы).

Поддерживаемые форматы: `.jpg, .jpeg, .tif, .tiff, .png, .bmp, .webp, .psd, .eps`  
(EPS — через Ghostscript; PSD — в пределах поддержки Pillow. Конвертации цветов нет.)

## 2. Системные требования
Запуск — из Docker image.

Для Docker:
- Docker 20+
- RAM: от 1.5–2 ГБ
- CPU: 1+ ядро (OCR — CPU), без GPU

Локально без Docker (для разработчика):
- Python 3.11
- Системный Tesseract OCR (rus+eng) доступен в PATH

## 4. Краткая логика валидатора

- Чтение файла и метаданных (размер, CMYK по mode/ICC, DPI, пиксели).
- Геометрия: при текущем DPI холст должен соответствовать 110×80 мм (обрез 100×70 + вылеты по 5 мм).
- Если «физика» нарушена — OCR не выполняется.
- Если «физика» без нарушений — OCR (rus+eng), получение границ текста.
- Расчёт минимального отступа текста от линии обреза; если меньше 5 мм — нарушение.
- Итог: «Можно печатать» / «Нельзя печатать» + перечень нарушений.

### Ограничения:
- нет автоконвертации цветов — только валидация;
- DPI берётся из метаданных файла;
- качество OCR зависит от контраста и читаемости текста;
- PSD поддерживается ограниченно библиотекой Pillow;
- очень большие изображения требуют больше памяти.
